# sa-data-pipeline
Live ETL pipeline for South African economic data — Bronze → Silver → Gold → DuckDB → Streamlit dashboard. Built with Python, Pandas and Open APIs.
python data-engineering etl duckdb streamlit pandas medallion-architecture world-bank-api south-africa data-pipeline portfolio

🚀 v1.0.0 — Initial Release

Full ETL pipeline pulling live SA economic data from the World Bank 
and Open Exchange Rates APIs. Implements Bronze → Silver → Gold 
medallion architecture, loads into DuckDB and renders on a Streamlit 
dashboard with KPIs, interactive charts and a pipeline audit log.

Built in Python. No paid APIs. No cloud costs. Runs locally.
